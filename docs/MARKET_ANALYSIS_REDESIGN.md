# 市場分析の整理・接続設計

調査日：2026-10-08〜09。実装・検証状態は [市場再構成の受入記録](MARKET_REDESIGN_ACCEPTANCE.md) を参照。以下は調査時点の設計と判断根拠です。

対象はローカルCodex版の「市場」。既存Reflex/HF、総覧の承認済み配置、個別株の主条件・会計・評価を変更する計画ではない。公開・課金・売買・commit/push/deployは対象外。

## 1. 結論と確認済みの方針

29個のサービス名を主画面に並べる方式から、5つの投資リサーチ上の質問に答える方式へ変える。単に展開欄へ押し込むのではなく、重要な数値・関係・反証を初期表示する。

- 中期の個別株研究（半年〜2年）と短期のタイミング確認（日〜週）を同程度の視認性で支える。短期見通しを中期の企業価値と同一視しない。
- 重複した判定、独自の未検証スコア、取得負荷の大きい研究モデルは、標準表示だけでなく標準更新からも外す。旧結果・詳細・明示実行の経路は残す。
- 必要最小限の無料・公表データを追加する。閲覧できることと、保存・加工・再配布できることを区別する。
- 新たな総合点、売買指示、自動配分は作らない。欠損は中立・安全・0にしない。

## 2. 他サービスから採る設計、採らない設計

## 3. 注目する指標の役割と限界

|情報の種類|答えられること|答えられないこと／扱い|
|---|---|---|
|指数のトレンド・移動平均・高安値|どの期間で上昇・下降・持合いか、現在価格の位置|企業価値、次の上昇確率、機関投資家の売買そのものは分からない|
|参加の広がり・相対強度|指数上昇が広い銘柄群にも及ぶか、どの分野が相対的に強いか|RSP/SPYは等加重対時価加重の代理比較。IWM/SPYは規模・構成の異なる指数比較であり、真の騰落銘柄数ではない|
|テーマの複数期間騰落と構成銘柄|中期の強さと短期の加速・失速、テーマ内部の偏り|テーマ順位だけで、財務健全性、割安さ、エントリー成立とは言えない|
|金利・信用スプレッド|割引率・資金調達条件・信用不安に関する背景|金利上昇だけで株安とは言えない。成長期待、インフレ、リスクプレミアム等を区別する仮説が必要|
|VIX・期間構造|S&P500オプションに織り込まれた変動の大きさ・近い期間の警戒|VIXは方向を示す指標ではなく、日本市場の予測でもない|
|原油・為替|コスト、輸出採算、資源収入に関する確認材料|株価と同時に動いたことだけで原因とは言えない。事業の通貨・価格感応度を別途確認する|
|実際の投資部門別売買・信用残|誰が、どの対象期間・範囲で買越／売越したか、残高がどう変わったか|当日の資金流入、全市場の残高、将来の買戻しの確約とは言えない|
|経済・政策イベント|次の情報更新の時点、短期の不確実性を確認する機会|発表前に結果や市場反応を決め打ちしない。無料の公式日程は市場予想値を含むとは限らない|

役割の根拠：参加度については[StockChartsの説明](https://stockcharts.com/freecharts/marketsummary.html)、相対モメンタムについては[AQRの研究](https://www.aqr.com/Insights/Research/Journal-Article/Fact-Fiction-and-Momentum-Investing)、金利曲線の解釈については[Fedの研究](https://www.federalreserve.gov/econres/notes/feds-notes/predicting-recession-probabilities-using-the-slope-of-the-yield-curve-20180301.html)、金利・資産価格の関係については[Fedの説明](https://www.federalreserve.gov/newsevents/speech/kohn20070322a.htm)、VIXの非方向性については[Cboeの定義](https://www.cboe.com/insights/posts/what-the-vix-and-vix-1-d-indices-attempt-to-measure-and-how-they-differ/)。一般的な研究・定義を、本アプリの個々の閾値や日米テーマの予測性能の実証と読み替えない。

移動平均、VIX、テーマ等を多数試して良さそうな組合せを採用すると、過剰適合の問題がある。[Baileyほかの論文](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)を踏まえ、独自の「確度」「上昇確率」「研究姿勢」は原数値から分離する。データ品質と予測精度は別項目にする。

## 5. 新しい主画面：5つの質問

### ① 中期：基調はどちらで、広がりは伴っているか

指数の3／6／12か月騰落、50／200日線との位置・傾き、参加の広がりの代理値をまとめる。半年〜2年の保有判断そのものではなく、その研究の市場背景である。

米国はSPY・QQQとRSP/SPY・IWM/SPY。日本は日経平均・TOPIXまたは明記したETF代理、登録されたテーマ構成銘柄の参加状況。日本の限定母集団を「東証全体の騰落率」にしない。

初期表示：小型の価格推移、主要数値3〜4個、支持する観測と弱める観測。各観測に日付と直接／代理を付ける。

### ② 短期：今はどの価格帯で、何が変われば見方を変えるか

最新終値、20日線からの距離、保存計算法による支持・抵抗、直近5／21営業日変化、出来高の確認、近いイベントを一緒に表示する。支持線を図示する価格は同じ銘柄・調整基準の価格でなければならない。

「中期上向き・短期抵抗付近」のように、同時に成り立つ状態を維持する。既存の現在／1週／1か月先を加重得点で一本化しない。短期は将来予測でなく、突破／維持／失敗を再確認する条件にする。

①②はデスクトップで同じ幅の2列、モバイルでは同じ情報量で縦並び。短期の色・表示面積が中期を圧倒しない。

### ③ 選別：どのテーマが強く、内部の銘柄も強いか

1週・1か月・6か月、同期間の市場相対騰落、対象銘柄数・取得率・観測日を同じ行に置く。標準は上位・下位各3〜5テーマ、代表銘柄は同じ行または直下に見える。全テーマへ移動しても市場・期間・選択テーマを保持する。

「中期優位＋短期加速」「中期優位＋短期失速」は単なる数値の組合せラベルとして表示。企業価値や購入条件とは別にする。代表が1銘柄に偏るテーマは、その集中と母数を示す。複数テーマに同じ銘柄があることを独立の裏付けとして数えない。

保存済み銘柄へ移動し、Stage2／RS／VCP／出来高／成長／Entry、会計・評価・資料を確認する。市場の警戒で個別株の主条件の数値を変更しない。市場更新で古い決算や評価を新しく見せない。

### ④ 背景：金利・信用・為替・ボラは何を弱め／支えているか

小型の共通表：US10Y／実質10Y／2Y・10Y差／JGB10Y／信用スプレッド／VIX・近期期限差／USDJPY／WTI。最初は全件の大型チャートでなく、水準・変化・観測日・役割を一覧にする。毎日、週次、月次を明記する。

米国信用は日本では「米国・外部環境」。日本固有の実需給は最新公表週の海外投資家の現物買越額を表示する。ETF相対騰落や出来高は「リーダーシップ・売買活発度」であり、資金流入額ではない。

例えば「原油高→輸入コスト圧力の仮説→小売・航空などのテーマで実際の相対弱さを確認→会社の調達・ヘッジを原資料確認」という接続を作る。業種一律の利益減少や因果関係を断定しない。

### ⑤ 統合：一致・食い違い・未確認、次の確認条件

①〜④の実際の根拠を再利用し、短い論点3〜5行を示す。新しい独立スコアや「強気が何票」ではない。

各行の形は「観測 → 解釈候補 → 反対／不足の根拠 → 解釈が変わる条件 → 確認先」。クリックすると引用した具体的な数値・テーマ・資料が強調される。詳細の汎用JSON表示を主たる説明にしない。

方針タブはこの統合論点を共有し、別の加重結論を作らない。Codexの解釈を添える場合も、観測・仮説・反証を分離し、参照したrun_idを保存する。AIの文章で数値状態を上書きしない。

### 初期表示から詳細へ分ける基準

初期表示には価格位置、複数期間、関連する根拠・反証、日付と不足を置く。展開欄には計算式、全履歴、全構成銘柄、研究モデル、入力検証表を置く。29項目分の空箱・同じ「未取得」・一般的な説明を主画面に残さない。未対応は一つの対象範囲欄にまとめ、取得失敗は関係する主分析の近くに残す。

## 7. 有機的な接続の計算・説明契約

### 根拠を束ねる単位

各観測に `evidence_id / series_id / market / instrument / currency / unit / price_basis / window / observation_date / period_start / period_end / published_at / fetched_at / source_url / quality / scope / parent_ids` を持つ。型・非有限値・順序・重複日を検証する。旧ファイルに日付がない場合は未記録のままにする。

同じSPY価格からMA・突破・モメンタム・IBDを作っても、4つの独立した証拠と数えない。VIX→volatility→sentiment→strategyの連鎖も親の系列を辿って一つの根拠群とする。テーマに重複登録された銘柄も同様。

### 関係の種類

- 支える：同じ対象・互換期間で、別の種類の観測が仮説を支持する。
- 弱める：同じ仮説を別の観測が弱める。必ず対象と窓を明示する。
- 時間軸が異なる：中期上昇と短期調整など。矛盾と呼ばない。
- 参考：米国信用を日本の背景として読むなど。日本固有判定には加算しない。
- 比較不能／未確認：日付、調整、範囲、入力が不足。安全側の結論も推測しない。

価格・出来高の同時変化は「観測された関連」。原油・金利→利益／評価への説明は「経済的仮説」。統計的な相関を表示するなら、使用期間・標本数・欠測・結果を別に計算し、因果や予測確率と呼ばない。第一版は相関ネットワーク図や機械学習の因果推定を追加しない。

### 固定ケースの表示例（条件を仮定した例であり、現在の相場判断ではない）

|観測の組合せ|接続した読み方|反証・次の確認|
|---|---|---|
|指数上昇、RSP/SPYとIWM/SPYは低下|大型・特定銘柄に偏る可能性。指数だけで広い参加を確認できない|限定母集団の銘柄参加、テーマ内部、等加重の回復を見る。小型劣後だけで全面悪化としない|
|50／200日線上だが短期抵抗付近、20日線乖離大|中期の基調と短期の追随しにくさは両立|支持維持・抵抗突破の後続観測を確認。中期を弱気に一括変換しない|
|VIX上昇、日次信用スプレッドは安定|株式の期待変動増大は観測、信用への同時波及は未確認|VIX期限差・最新信用日を確認。月次ストレス指数で当日の安心を断定しない|
