# UI総合改善計画（履歴資料）

更新日: 2026-06-12

## デザインブリーフ

- 現行のReflexアプリ、青・グレー基調、既存ルート、既存操作、既存分析機能を維持する
- 全5画面を対象に、情報階層、スキャン速度、データ状態、画面間一貫性、基本レスポンシブを改善する
- 投資判断に見える値は、値だけでなく取得元・算出方法・制約を追跡可能にする
- 大規模な見た目の刷新ではなく、既存デザインを段階的に洗練する

## 2026-06-11 実装済み基盤

### 共通UI

- 共通のページヘッダー、セクション見出し、読込状態、空状態を追加
- 固定サイドバーを大画面用とし、狭い画面では5ルートを収めた左ドロワーへ切り替え
- 全画面の余白を画面幅に応じて調整
- ヘッダー重複を減らし、トップバーを共通ユーティリティ表示へ変更
- 絵文字だけに依存していた主要操作を、アイコンとテキストの組み合わせへ変更

### データ信頼性表示

- direct、computed、proxy、estimated、model output、fixed fallback、stale cache、unavailable の共通来歴契約を追加
- Market、Market Watch、Stock、Portfolioへ「データの来歴・信頼性」パネルを追加
- 来歴パネルで取得元、算出方法、制約、リスクレベル、基準日時を確認可能にした
- 固定値で補完していたPCR、米10年債利回り、SPY PER、NDX PERを廃止し、欠損時は利用不可として扱う

### 画面別

- Market: データ来歴とAI Market Recapを主要資産一覧より先に配置
- 市場監視: 段階更新状態とデータ来歴を先頭に配置し、既存の詳細分析順を維持
- Stock: 検索フォームをレスポンシブ化し、企業概要直下に来歴を表示。主要指標、チャート、ニュースの狭幅表示を改善
- Portfolio: 管理画面と分析画面を明確化し、価格未取得銘柄をゼロ評価せず、警告付きで分析対象から除外
- Knowledge: 追加・編集・空状態を共通化し、「AIに学習させる」を実態に合う「AI参照に追加」へ変更

### Product Design / Browser監査

- 全5ルートをdesktop `1440x900`、tablet `834x1112`、mobile `390x844` で確認
- 全15条件で横方向オーバーフローなし、Browser接続エラーなし、未ラベルボタン0件を確認
- モバイルのナビゲーション折返しを検出し、横並びナビゲーションから左ドロワーへ修正
- 通常、読込、空状態を実画面で確認。partial、stale、errorは回帰テストと共通状態表示で確認し、決定的なBrowser fixtureは今後整備する
- 監査結果とスクリーンショットは [`docs/ui-audit/2026-06-11/`](ui-audit/2026-06-11/README.md) に保存

## 次の改善フェーズ

### Phase 1: 分析画面の分割

- `frontend/components/flash_summary.py` を市場判断、Regime、Flows、Credit、Options、Japan条件へ分割する
- `frontend/pages/stock.py` を概要、チャート、評価、診断、AI Recap、ニュースへ分割する
- 画面上部に「現在の判断」「主要変化」「主要リスク」の要約カードを追加する

### Phase 2: 状態と操作

- partial、stale、failed、emptyの各状態に専用メッセージと再試行操作を追加する
- データ来歴パネルを折りたたみ可能にし、個別指標から該当来歴へ移動できるようにする
- 削除操作へ確認ダイアログを追加する
- フォームのラベル、説明、バリデーション、キーボード操作を統一する

### Phase 3: 可視化と比較

- MarketとStockの重要指標へ期間比較と基準値を追加する
- proxy値と直接値を同じチャートへ混在させる場合、線種・ラベル・説明で明確に区別する
- Portfolioへ構成比、価格未取得比率、集中度の可視化を追加する

## 検証基準

- 全5ルートがデスクトップ、タブレット、モバイル幅で主要操作を実行できる
- 色だけに依存せず、ラベルでも状態を判断できる
- 欠損、proxy、推定、staleが直接値と誤認されない
- 読込中、空、部分成功、取得失敗で画面全体が消えず、利用可能な情報を維持する
- `compileall`、`ruff check`、`ruff format --check`、`pytest`、Reflex frontend exportが通る
