## 入口と画面

`Open-Investment-Research.cmd`を起動する。起動と「保存結果を表示」は取得しない。「市場・価格」「業績」「両方」の更新を選ぶ。市場は日米・日本・米国。旧研究詳細の更新は従来どおり明示選択する。

| 画面 | 最初に確認する内容 | 操作・詳細 |
|---|---|---|
| 総覧 | 中期基調、短期位置、市場参加、外部環境 | 指数比較、業種要約、強い・改善中のテーマ |
| 市場 | 4観点の地合いと60営業日の参加状況 | 直近21営業日の観測日誌、出来高増加を伴う下落日、旧接続分析・研究詳細 |
| 業種・テーマ | 中期の相対優位と最近の改善・鈍化 | 比較表、同面積ヒートマップ、強さ・勢い図、売買活発度、構成内訳、数値ソート、CSV |
| 銘柄 | Stage 2・相対強度・出来高・業績条件 | 一覧、チャート、ヒートマップ、検索、業種・テーマ絞込、条件プリセット、候補詳細、既存保存分析 |

候補一覧のプリセットは全登録、先導株上位50、Stage 2、高値圏、出来高急増、ポケットピボット参考、EPS加速、Code33参考。条件が不明な銘柄は合格にしない。ピンはブラウザのlocalStorageに保存し、外部送信しない。

## 母集団と定義

- 米国76テーマ・318銘柄、日本34テーマ・117銘柄。市場参加はテーマ重複を除いた登録標本であり、市場全銘柄の統計ではない。業種は米国11 ETF、日本17 ETF（1617.T–1633.T）。ETFは指数そのものではなく代理系列。
- 期間は1日/1週/1か月/3か月/6か月/1年＝1/5/21/63/126/252営業日。テーマ騰落率は構成銘柄中央値、市場相対値は同期間の中央値と基準ETFの差（pp）。有効数60%以上かつmin(3,登録数)が必要。基準はUS=SPY、JP=1306.T。取得不能な相対値は別指数に置換しない。
- 中期基調は終値と200日線の位置、200日線の20営業日前比。短期は20/50日線の位置を別表示する。市場全体・個別株の新しい複合点数は作らない。
- 強さ・勢い図は横軸6か月市場相対値、縦軸1か月市場相対値の21営業日前との差。境界0は境界として扱う。12週の軌跡は現在の登録構成による再計算であり、当時の構成を復元した成績でも公式RRGでもない。前週順位差は同一の比較可能集団内で計算する。
- 市場参加は20/50/200日線上、252日高安値から2%以内、前日比上昇/下落の比率。各日・各指標に分子分母を保存し、欠測を前日値や0で埋めない。JP相対基準が不良でも、利用可能な日経平均の営業日暦で絶対価格・参加・Stage 2を計算する。相対値の代替には使わない。
- 出来高急増は当日出来高/直前50営業日平均が1.5倍以上。ポケットピボット参考は終値上昇・10日線上・直前10営業日の下落日最大出来高超え。比較下落日がなければ不明。売買活発度は資金純流入や機関投資家の買い集めを示すものではない。
- 出来高増加を伴う下落日はETFで前日比-0.2%以下かつ出来高増。直近25営業日内、発生日終値から5%回復または期間経過で失効する研究代理指標。指数の公式distribution day判定ではない。

Stage 2/VCPは既存の共有価格条件計算を利用する。候補詳細にはMA・出来高・市場ETFとの比率を表示し、独立した条件を確認する。画面内の先導株候補は売買推奨や財務照合済み一覧ではない。

## 四半期業績の取得と原資料確認

Pythonの`Quarter`契約に、単独四半期の開始/終了、通貨、売上、親会社帰属純利益、希薄化EPS、会計・連結範囲・帰属・分割基準、出典、公開/取得日、確認状態を保持する。金額は基準通貨単位、EPSは通貨/株。累計EPSの差し引き、基本EPSの代用、欠損の推計はしない。

自動取得は米SEC Company Facts（適切な`SEC_USER_AGENT`設定がある場合）とYahoo四半期損益。銘柄ごとのローカルチェックポイントは7日有効で、途中から再開できる。自動取得と原資料照合は別工程。SECの単独四半期/同一提出書類を選別するが、分割等の基準が揃ったと確認できない系列は加速判定を止める。既存の確認済み入力は自動更新で消さない。確認済み入力がある場合、条件判定と絞込はその確認済み期間を使い、新しい自動候補を未照合の別欄で表示する。確認済み期末・確認日を併記し、自動取得日で確認日を更新しない。

Code33参考は直近3四半期とその各前年同期が必要。EPS・売上の前年同期成長率がいずれも正で連続上昇し、親会社純利益率も正で連続上昇した場合に成立する。前年EPSが0以下の黒字転換は別表示。会計・通貨・帰属・連結範囲・分割基準が不一致なら比較不能。金融・REIT等には一律適用しない。無料取得が5期だけなら不足のまま残す。

確認入力は`ResearchEvidence(schema_version=3, sources=..., quarterly_records=...)`として、公開日・確認日・ページ/表・引用箇所を記録する。同一銘柄の確認済み一次資料への参照が必要。`--resume`は通信せず新しい保存結果を作り、以前の株価・評価・会計照合は維持する。

```powershell
# 通常は価格と地合い。業績も取得する場合は明示する。
.venv\Scripts\python.exe scripts\research.py update --scope all --profile standard
.venv\Scripts\python.exe scripts\research.py update --scope all --include-fundamentals
# 保存された候補だけを開く。下は業績の明示更新を伴う。
.venv\Scripts\python.exe scripts\research.py screen --market US --open
.venv\Scripts\python.exe scripts\research.py screen --market JP --refresh-fundamentals
# 原資料確認入力を保存結果へ適用する（新規取得なし）。
.venv\Scripts\python.exe scripts\research.py overview --resume <research.json> --evidence <reviewed-quarters.json>
```

## 保存・互換性と所有境界

新規はschema v3、既存v1/v2も読込可能。1ファイル20MiBまで、混合複数読込は全件検証後に反映し、失敗時は前画面を維持する。v3はコンパクトJSON。Pythonは市場参加の分子分母、四半期からの加速条件・比較値、確認済み出典を検証する。ブラウザの検証は形状・日付・型を検査するが、原資料の真実性を保証しない。

計算責務は`topdown.py`/`quarterly.py`、取得は`standard.py`/`fundamentals.py`、更新は`workbench.py`、描画は`assets/topdown.js`。画面は保存値を表示し、データ取得・モデル呼出しをしない。localhost入口のHost/Origin/トークン/本文上限と更新ロックは維持。保存ファイルや会計・企業価値の旧基準日は上書きしない。
